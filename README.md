# UN Trade over Aid

This repository is the canonical home for the Trade-over-Aid research project.

## Product goal
A brief, informative, evidence-driven white paper (2–3 pages), supported by abundant, intuitive visualizations. Detailed sources, datasets, scripts and unresolved questions belong in supporting materials.

## Evidence standard
Keep reported delivery, financing, scheduled activities, eligibility, historical records and unresolved evidence distinct. Never label unresolved awards verified active. Missing evidence is not evidence of inactivity.

The validated research package and supporting materials are being imported into this repository.
